GOOD TO KNOW

A few small details.

Is NOVA OS free? ＋

Yes, NOVA OS is currently free to download and use.

Which Macs does it support? ＋

NOVA OS supports macOS 13 and later, including Apple silicon and Intel Macs.

How do updates work? ＋

Version 1.2.0 Orbit is installed manually using the package above. The original Sparkle signing key was unavailable for this release, so the automatic-update feed still advertises 1.1.6.

What powers NOVA OS? ＋

It's a native macOS app built with Apple's WebKit, with NOVA Search and optional AI-generated overviews of search results.
