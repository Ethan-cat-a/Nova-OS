GOOD TO KNOW

A few small details.

Is NOVA Browser free? ＋

Yes, NOVA Browser is currently free to download and use.

Which Macs does it support? ＋

NOVA Browser supports macOS 13 and later, including Apple silicon and Intel Macs.

How do updates work? ＋

Version 1.1.7 Frost needs to be installed manually using the installer above. The existing Sparkle automatic-update feed has not yet been updated for this release.

What powers NOVA Browser? ＋

It's a native macOS app built with Apple's WebKit, with NOVA Search and optional AI-generated overviews of search results.
