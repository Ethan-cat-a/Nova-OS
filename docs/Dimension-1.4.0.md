# NOVA OS 1.4.0 — Dimension

Morph is a constrained local intent interpreter, not a general-purpose AI code generator. It maps supported language to five reviewed CSS styles, applies them in a separate WebKit JavaScript world, and can remember an exact origin. Reset removes the stylesheet and saved rule. It does not remove access controls, execute user-generated JavaScript, or transmit page text. Some sites may prevent custom styling. Command-Shift-M.

Dimension is a bounded 3200 × 2400 spatial canvas for each existing Flow Space. Add website URLs, import existing website tabs, add and edit notes, drag headers and zoom. Live website cards load only on explicit activation, using separate nonpersistent WebKit storage without NOVA's native message bridge; up to four run at once. Pausing or closing the board destroys live views. Open tab opens the card's stored URL in the normal browser. No automatic login sharing. Cards are limited to 40 per Space. This is a first canvas release, not a fully infinite desktop or arbitrary app builder. Command-Shift-D.

State and UI are separated into MorphDimensionState.swift and MorphDimensionUI.swift. Unit tests exercise supported intents, origin validation, bounds, quotas, round trips and rejecting unsafe URLs. Mac CI builds and validates a universal installer. Manual GUI QA: apply/reset on several sites, navigate with remembered styles, move notes and live tiles, close/reopen boards, switch Spaces, test scrolling/zoom and page interactions on macOS 13+. No claim of complete GUI validation unless performed. Existing 1.3.0 remains rollback. Preserve the search service rewrites and existing Sparkle keys.
